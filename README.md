# Gaussian Pulse Propagation in Optical Fibers 🫧✨

Welcome to my repository! 🧸 This project contains a Python-based simulation exploring how optical pulses behave as they travel through different media.

Rather than detailing the physics here, I invite you to dive directly into the code and visualizations. 

## 🎀 What's Inside?
- **`pulse_propagation.ipynb`**: The core simulation file. It contains the complete step-by-step mathematical modeling, algorithm design, and dynamic graphs visualizing Group Velocity Dispersion (GVD) and chirping effects.

## 🦋 How to View
Simply click on the `pulse_propagation.ipynb` file above. GitHub will automatically render the Jupyter Notebook, allowing you to seamlessly read the academic report and examine the Matplotlib plots without needing to download anything.
